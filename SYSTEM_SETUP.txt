

PHP 7.3+ compatibility
-----------------------
This package suppresses PHP dynamic-property deprecation notices generated by CodeIgniter 3.1.13. These notices are framework compatibility warnings, not application failures.

MySQL/XAMPP
-----------
The application expects MySQL/MariaDB at 127.0.0.1 with username root, an empty password, and database bike_shop. Start Apache and MySQL in XAMPP, then import data/bike_shop.sql into phpMyAdmin. If your MySQL root password is not empty, update application/config/database.php.
